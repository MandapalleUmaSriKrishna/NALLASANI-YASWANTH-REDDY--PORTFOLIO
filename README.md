# 🌍 Deployment

This portfolio can be deployed easily using **GitHub Pages**.

1. Push the project to GitHub.
2. Open **Settings**.
3. Select **Pages**.
4. Choose:
   - Source → Deploy from a branch
   - Branch → main
   - Folder → /(root)
5. Save.
6. Wait a few minutes.
7. Your website will be live.
